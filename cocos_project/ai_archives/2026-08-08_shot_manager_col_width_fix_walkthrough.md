# MasterManager ShotManager カラム幅調整・自動保存の修正完了報告

ユーザー様からのご指摘を受け、幅が均等に全画面引き伸ばされていた原因を修正し、各カラムに自然な初期幅（コンパクト化）を設定するとともに、ドラッグした列幅が `localStorage` へ確実に保存・復元されるように修正いたしました。

---

## 修正内容

### 1. テーブルの `width: 100%` 強制引き伸ばしの撤廃
- 以前の CSS に含まれていた `min-width: 100%` および `width: 100%` により、各列が親幅に合わせて強制的に均等引き伸ばされていた問題を削除・撤廃しました。
- 各カラム（`ID`, `Type`, `Count`, `SP`, `DMG`, `WT`, `PrefabName`, `Comment`）がそれぞれのデータに応じた自然でコンパクトな基本幅で表示されるようになりました。

### 2. ドラッグでの列幅調整および `localStorage` 自動保存の修正
- 列幅取得時のキーを `ShotManager.csv::colKey` として統一し、ドラッグ終了時に `setColWidth` を経由して `localStorage` (`master-manager-col-widths`) に即座に保存・永続化するよう補正しました。
- パネルの再読み込みや Cocos エディタ再起動後も、ユーザー様が自由に調整した列幅がそのまま維持されます。
