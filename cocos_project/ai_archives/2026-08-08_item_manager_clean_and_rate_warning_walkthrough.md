# ItemManager 仕様整理 ＆ DropTableIDManager Rate合計1.0警告機能の導入報告

ご質問いただいた項目の回答・解説および、ご要望いただいた `ItemManager` の `Rate` 削除、`DropTableIDManager` での Rate 合計チェック（⚠️警告表示機能）を完了いたしました。

---

## 1. ご質問への回答

### Q1. Min と Max は何のための数字だったか？
- **A. ドロップ成功時に生成される「アイテムの個数範囲」を指定するパラメータです。**
  - 例: `Min: 1, Max: 1` ➜ ドロップ成功時に**必ず1個**生成。
  - 例: `Min: 1, Max: 3` ➜ ドロップ成功時に**1〜3個のランダムな個数**をまとめて放出・生成。
  - お金（`ItemMoney`）など、一度に複数個ばら撒きたいアイテムなどで活用できます。

### Q2. DropTableIDManager の Rate は 1.0 = 100% という認識でOK？
- **A. はい、そのご認識で100%正解です！**
  - `1.0` = 100%（確定ドロップ）
  - `0.5` = 50%
  - `0.1` = 10%
  - `0` = 0%（ドロップなし）

## 2. 主な変更点

### ① `ItemManager` (`Items.csv`) から `Rate` を削除
- `Rate` は `DropTableIDManager` 側で個別の出現確率として管理されるため、`ItemManager` の定義項目から削除・整理いたしました。

### ② `DropTableIDManager` での Rate 合計 1.0 チェック＆ ⚠️ 警告表示機能を追加
- **警告表示ロジック**:
  - `DropTableIDManager` タブ (`DropTables.csv`) において、有効なアイテム（`None` 以外）の `Rate_1`〜`Rate_5` の合計値をリアルタイム計算します。
  - 合計値が `1.0` になっていない場合（例: `0.85` や `1.20` など）、**IDの左側に ⚠️ 警告アイコン**を表示し、セル背景を強調表示します。
  - ⚠️ アイコンや ID セルにカーソルを合わせると、`⚠️ Rate合計が 1.0 になっていません (現在の有効合計: 0.85)` というツールチップが表示されます。
  - 値を編集した際もリアルタイムで警告表示が更新・解除されます。
